# Flujo de trabajo
Cada miembro crea una rama a partir de desarrollo con el formato tarea-nombre de-la-tarea. 
Se realizan cambios en su rama y los sube al repositorio remoto.
Se crea un pull request hacia desarrollo, se aprueba por el líder y se mergea.
Una vez que todas las tareas están en desarrollo, se crea un pull request para integrar los cambios en Final.
